# Digests

Periodic rollups — weekly reviews, portfolio pulses, status updates, batch-day digests. Not
minutes of any single meeting: those live in the sibling type folders.

**Read this when:** You want last week's digest, the latest portfolio pulse, or a past
status update.

One folder, four writers, told apart by filename prefix (registry: `.claude/references/write-back-contract.md`, "One writer per surface"):

| Pattern | Writer |
|---------|--------|
| `{YYYY}-W{XX}-weekly-review.md` | `/weekly-review` |
| `{YYYY-MM-DD}-portfolio-pulse-{mode}.md` | `/portfolio-pulse` |
| `{YYYY-MM-DD}-status-{audience}.md` | `/status-update` |
| `{YYYY-MM-DD}-daily-batch.md` | `/process-meeting` (batch mode) |
