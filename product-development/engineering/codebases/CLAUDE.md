# Codebase Maps

SHA-stamped tables of contents for the *large* repos in [../code-repos.yaml](../code-repos.yaml) — routing hints for `/code-qa`, generated by `/connect-code`. Most repos don't need one: grep-first navigation works without a map.

**Read this when:** You need to know where something lives in a product repo before opening it.

Rules:

- Maps route, they never prove — cite code lines, not map lines (contract: `.claude/references/code-grounding.md`).
- Every map header stamps `{repo}@{full-sha}` + generation date. Written only by `/connect-code` (including `--refresh`).
- Keep each map ≤150 lines — it is a table of contents, not documentation.
